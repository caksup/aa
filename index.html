info Format Teks Parse
[sesi: ID_SESI] ← opsional, pakai selector di atas [mapel: B. Inggris] ← opsional 1. Pertanyaan? A. Pilihan A B. Pilihan B C. Pilihan C D. Pilihan D j:b ← PGS (huruf tunggal a-d) j:a,c ← MCMA (lebih dari 1, koma) j:goes ← ISIAN (teks bebas) Statement 1: ... ← Kategori Benar/Salah Statement 2: ... j:benar,salah ← kunci per pernyataan (b/s, true/false, 1/0) [gambar: https://.../gambar.jpg] ← opsional, setelah nomor soal [pembahasan] 1. Penjelasan soal 1 2. Penjelasan soal 2 3. b,s ← format kunci lama (opsional)
Posisikan kursor di soal sebelum menyisipkan. Format: [gambar: URL]. Upload JPG/PNG/WEBP/GIF maksimal 5 MB.
Format CSV (delimiter titik koma ;):
Pilihan Ganda: PGS;Teks soal;optA;optB;optC;optD;[optE];Kunci;Penjelasan;URL_GAMBAR; (sesuai template CSV)
Pilihan Ganda Kompleks: MCMA;Teks soal;optA;optB;optC;optD;optE;A,C;Penjelasan;URL_GAMBAR;
Kategori Benar/Salah: PGK;Instruksi;;;;;;true,false;Penjelasan;URL_GAMBAR;Pernyataan 1|Pernyataan 2
Isian: ISIAN;Teks soal;;;;;;goes;Penjelasan;URL_GAMBAR;
Kunci Benar/Salah menerima true/false, benar/salah, B/S, atau 1/0. Gunakan template CSV agar kolom tetap sejajar.

Homework / PR = sesi yang dikerjakan siswa di rumah dengan deadline. Mendukung mode retry conditional (2x bila nilai <50 atau benar <setengah) untuk mendorong perbaikan.

Realtime Exercise (ala Quizizz) = sesi host-led dengan lobby, timer sinkron, dan leaderboard live. Guru membuka Host Dashboard, siswa join via kode. Hasil otomatis masuk Riwayat & Laporan.
